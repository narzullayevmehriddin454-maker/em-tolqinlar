FAYLLAR:
--------
- index.html              -> Asosiy HTML sahifa

- assets/index-*.css      -> Sayt dizayn (Tailwind CSS bundle)

- opengraph.jpg           -> Ijtimoiy tarmoq uchun rasm
- robots.txt              -> Qidiruv tizimlari uchun

ISHGA TUSHIRISH:
----------------
1) Eng oson yo'l: butun papkani GitHub Pages, Netlify, Vercel yoki
   shunga o'xshash statik xosting xizmatiga yuklang.

2) Lokal sinab ko'rish (kompyuteringizda):
   Papka ichida terminal oching va quyidagini bajaring:
       python3 -m http.server 8080
   Keyin brauzerda http://localhost:8080 manzilini oching.

3) GitHub Pages uchun:
   - GitHub'da "mehriddin.github.io" nomli yangi repository yarating
   - Shu papkadagi hamma fayllarni shu repoga yuklang
   - Settings -> Pages bo'limidan "main" branchni tanlang
   - Bir necha daqiqada sayt https://mehriddin.github.io manzilida ochiladi
